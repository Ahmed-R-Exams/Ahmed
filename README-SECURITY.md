# ملاحظات أمان — ما تم إصلاحه وما يحتاج عمل إضافي

## ✅ تم إصلاحه في الكود

- **`Firebase.js` → `firebase.js`**: كان اسم الملف الفعلي مختلفًا عن كل الاستيرادات
  بحالة الأحرف، وهذا يفشل البناء على أي سيرفر حساس لحالة الأحرف (Linux, Vercel,
  Netlify, GitHub Actions). تمت إعادة تسميته.
- **تقليل تعرّض الإجابات الصحيحة**: كائن الامتحان الكامل (بما فيه
  `correctAnswerIndex`) لم يعد يُخزَّن في `localStorage` طوال مدة حل الامتحان.
  الآن يُخزَّن مرجع خفيف فقط (`currentActiveExamRef`)، وتُجلب بيانات الامتحان
  الكاملة من Firestore وقت العرض وتبقى في ذاكرة الجافاسكريبت فقط.
- **`firestore.rules`**: أضفت ملف قواعد أساسي لم يكن موجودًا إطلاقًا في
  المشروع. راجعه وعدّله حسب حاجتك قبل الرفع، ثم:
  ```
  firebase deploy --only firestore:rules
  ```
- تفعيل مؤقت الامتحان، وإعدادات المعلم (إظهار الدرجة/الإجابات/المراجعة)،
  واحترام إعداد الخلط العشوائي — كلها موضحة في الرسالة السابقة.

## ⚠️ لسه موجود ومهم تعرفه (يحتاج تصميم Backend)

**المشكلة الجذرية**: التصحيح (مقارنة إجابة الطالب بالإجابة الصحيحة) يحدث حاليًا
داخل متصفح الطالب نفسه، لأن التطبيق كله Frontend فقط بدون خادم. مهما قلّلنا من
تخزين الإجابات في localStorage، فبيانات الامتحان (ومنها الإجابة الصحيحة) **لازم
تصل لمتصفح الطالب في مرحلة ما** ليقدر التطبيق يصحح الإجابة محليًا ويحسب الدرجة.
طالب متمرّس بأدوات المطوّر (Network tab أو Debugger) يقدر يوصلها.

**الحل الكامل** يحتاج:
1. تخزين الإجابات الصحيحة في مجموعة Firestore منفصلة غير قابلة للقراءة العامة
   (مثلاً `examAnswerKeys/{examId}`)، بحيث لا تُرسل للمتصفح إطلاقًا.
2. **Cloud Function** (تحتاج خطة Firebase Blaze — مدفوعة حسب الاستخدام) تستقبل
   إجابات الطالب فقط، تقارنها بالإجابات الصحيحة على الخادم، تحسب الدرجة، وتحفظ
   النتيجة — كل ده من غير ما الإجابة الصحيحة توصل للمتصفح أبدًا.
3. تعديل `createExam.js` / `excelService.js` ليحفظوا الإجابات في المجموعة
   المنفصلة وقت إنشاء الامتحان.

هذا تغيير معماري حقيقي (مش مجرد تصحيح باج) ويحتاج قرار منك: هل تستحق منصتك
الحالية هذا المستوى من الحماية الآن، وليك استعداد لإعداد Cloud Functions
ومتابعة تكلفتها؟ لو الإجابة نعم، أقدر أبدأ في تنفيذه في خطوة تالية منفصلة حتى
لا يتشابك مع باقي الإصلاحات.
